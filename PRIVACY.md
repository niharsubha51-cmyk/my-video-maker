# NovaReel Studio MVP Privacy

The site is fully client-side and makes no application API calls. Video ideas, story scenes, narration scripts, metadata and saved projects are stored only in the visitor's browser via localStorage. Animated storyboard video is assembled in that browser via Canvas and MediaRecorder and downloaded locally. Voice preview, when used, uses the device's built-in browser speech feature. We do not collect names, email addresses or payment details, and no automatic YouTube upload occurs.

The hosting provider may process standard HTTP connection data under its own terms. Clearing the browser's site data removes saved projects. This is an MVP privacy notice and may need updating before adding analytics, accounts, YouTube OAuth or external AI services.
